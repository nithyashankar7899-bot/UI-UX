# FoodDeliveryApp – UI/UX Design

## Overview

FoodDeliveryApp is a UI/UX design project created as part of my CodeAlpha UI/UX Internship.

The project focuses on designing a simple, clear, and user-friendly food delivery application.

## Project Tasks

### Task 1 – Wireframing & Low-Fidelity Design

Created low-fidelity wireframes to define the basic layout, screen structure, navigation, and user flow of the application.

### Task 2 – High-Fidelity UI Design

Converted the wireframes into a high-fidelity UI design by adding colors, typography, buttons, icons, images, and other visual elements while following UI/UX principles.

## Design Tool

- Figma

## Project Structure

- Task-1-Wireframing – Low-fidelity wireframes and documentation
- Task-2-High-Fidelity – High-fidelity UI design and documentation

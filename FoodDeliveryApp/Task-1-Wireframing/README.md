# Task 1 – Wireframing & Low-Fidelity Design

## Description

As part of my UI/UX Internship at CodeAlpha, I completed Task 1 – Wireframing & Low-Fidelity Design.

I created low-fidelity wireframes for the FoodDeliveryApp in Figma, focusing on the basic layout, screen structure, navigation, and user flow.

The wireframes were designed with a simple and clear approach to establish the foundation for the final UI design.
